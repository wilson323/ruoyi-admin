## 三、端点契约（后端已就绪可直接对接）

### 3.1 页38 需求门户-游客提交

```
POST /api/v1/public/demands
  请求：GuestDemandSubmitReq { scenario, productCode, expectedScenario, content, contactName?, contactPhone?, contactEmail? }
  返回：GuestDemandSubmittedView { queryCode (8 位), initialStatus }
  公开端点（IpdWebSecurityConfig 已放行 /api/v1/public/**）

GET /api/v1/public/products
  返回：List<PublicProductView> （公开产品下拉，仅在售/在研/其他）

GET /api/v1/public/demands/{code}
  返回：PortalDemandTraceView （脱敏进度视图，仅查询码可见）
```

约束：游客提交仅返回 8 位查询码，不暴露内部 ID / 人员信息（BR-REQ-03）

### 3.2 页39 需求门户-查询进度

```
GET /api/v1/public/demands/{code}
  输入：queryCode（8 位）
  返回：PortalDemandTraceView （同 3.1 第三条）
  用途：游客凭查询码查脱敏进度（AC-REQ-04）
```

注意：补登/撤回在 Service（GuestDemandService.supplement/withdraw）但当前**无 HTTP 端点**，需前端会话决定是否要补 `/public/demands/{code}` 的 PUT/PATCH 端点，或降级为仅展示。

### 3.3 页48 AI 模型配置

```
POST /api/v1/ai-models
  请求：AiModelSaveReq 白名单 { modelName, baseUrl, apiKey, temperature, maxTokens, systemPrompt }
  返回：AiModelView （不含 api_key 明文/密文，仅脱敏掩码）
  权限：ipd:ai-document:add
```

约束：id / enabled 不可注入；update 时 apiKey=null 表示不改密钥；密钥不回显

### 3.4 页42 AI 文档助手

```
POST /api/v1/ai-documents/generate                 （PM 录入原始资料 → AI 输出 v1）
POST /api/v1/ai-documents/{id}/revise              （人工改版，HEAD 校验基准）
POST /api/v1/ai-documents/{id}/versions/{vid}/review （人工审核通过 → REVIEWED）
POST /api/v1/ai-documents/{id}/versions/{vid}/archive （归档，REQUIRED REVIEWED）
POST /api/v1/ai-documents/{id}/versions/{vid}/reject   （审核拒绝 → REJECTED，comment 必填）
GET  /api/v1/ai-documents/{id}/versions            （完整版本链 v1..vN）
GET  /api/v1/ai-documents/{id}/history             （版本链回溯视图）
GET  /api/v1/ai-documents/{id}/diff?from=&to=      （任意两版本字段级 diff）
```

业务串联：`GENERATED → REVIEWED → ARCHIVED`（+ `REJECTED` 兜底）

**风险提示（BR-AI-04，后端不审）**：前端在 AI 输出展示位置必须有「AI 生成、未经审核」角标 + 「确认无误请走审核流」提示。
