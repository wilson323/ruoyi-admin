### 9.3 Steps（6 步）

1. Checkout（`actions/checkout@v4`，`fetch-depth: 0`）
2. Setup pnpm（`pnpm/action-setup@v4`，`version: 10.14.0`）
3. Setup Node.js（`actions/setup-node@v4`，`node-version: 22.22.3`，`cache: pnpm`）
4. Install dependencies（`pnpm install --frozen-lockfile`，不跑 lifecycle 脚本）
5. **Run vitest with coverage** —— 单条命令：

6. Upload coverage artifact（`actions/upload-artifact@v4`，`name: ipd-coverage-lcov`，

### 9.4 阈值失败语义（不需额外解析脚本）

`@vitest/coverage-v8` 在阈值跌破时直接 emit `ERROR: coverage threshold for X not met`
并以 exit code ≠ 0 退出。GitHub Actions 因此把整个 step 标红、job 标红、
PR status check 标红——天然门禁，**无需自定义解析脚本**（区别于 typecheck 的
21-错误基线门禁，那里走自定义 `typecheck-error-count.mjs`）。
