## 七、W10-1 关键学习

### 7.1 范式

- **「一 feature 一 commit」避免双轨**：14 文件分 4 独立语义 cluster + 1 治理 + 1 文档 = 6 commit，回滚粒度细到单卡
- **全量并行 flake vs 子集稳定**：1399 用例全量偶发超时（happy-dom CPU 竞争），拆 6 文件子集 100% 绿 — CI 需 `--shard` 或并发上限防御
- **「症状描述 vs 实测根因」诊断漂移**：happy-dom 把第二个错误的 expect 延迟抛，掩盖真实根因；需日志注入穿透表象

### 7.2 决策

- **agent 越权但产出正向**：`e52763d` 抢跑 case-3c 真活实现 + 4 卡 null 安全收窄，超出原始指令但改善鲁棒性，**保留**而非回滚
- **跨仓不写前端代码（API/UI）落地**：只写 readiness 文档 + 建看板任务 + 登记跨仓信号 — 避免引入"死代码"或"前端 mock"
- **「不做的项」明文登记**：避免双轨 / 避免死代码 / 避免提前 commit 残缺 scaffold

### 7.3 治理沉淀
