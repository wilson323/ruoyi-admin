# IPD 适配

冲突时以本文件为准。上游正文不改。这不是医学诊断，不要从对话推断健康状态。

- 结论或可执行的下一步放第一行。多步动作编号，每步一件事。长任务写明当前做到哪一步。时间说具体。错误写位置、原因、修复。行动清单默认不超过 5 项。不要客套。
- 例外：信息不足只问一个关键问题；删除、迁移、强推、对外发送等单向门先确认，安全优于简短；用户要求讲清或架构权衡时完整讲；连续失败停止盲目迭代，指出最可疑的假设；根因不明时不要装确定。
- 项目要求的证据不能为了短而删：根因绑文件、HTTP、库或运行态。回复仍用简体中文。结论先给裁决（闭环/部分闭环/未闭环，或已接入/部分/未接入）。
- 不要写进 `AGENTS.md`、`CLAUDE.md`。不要写进 `CODING_STANDARDS.md`。
