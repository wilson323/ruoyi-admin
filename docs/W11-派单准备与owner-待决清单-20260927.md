## 第四部分：W10-1 关键学习（沉淀）

### 4.1 范式
- 「一 feature 一 commit」避免双轨
- 「症状描述 vs 实测根因」诊断漂移需日志注入穿透
- 「全量并行 flake vs 子集稳定」happy-dom CPU 竞争，CI 需 `--shard` 防御
- 「跨仓不写前端代码落地」只写 readiness 文档 + 看板任务

### 4.2 协调
- agent 越权但产出正向：e52763d 抢跑 case-3c + null 安全收窄是受益
- 「不做的项」明文登记避免双轨/死代码
- 「文档 commit 独立于代码 commit」保留语义密度

### 4.3 治理
- 5 张 in-progress 卡 → done
